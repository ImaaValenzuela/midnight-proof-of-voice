# Evaluation plan

There are no measured biometric or proof-performance results yet. Store evaluation
code and aggregate reports here; never commit recordings, templates, or identity
mappings. Keep consented datasets in access-controlled private storage.

Report model and dataset versions, language/device conditions, calibrated operating
point, sample counts, false acceptance/rejection rates with uncertainty, attack
success by attack family, and separate verifier, proving, submission, confirmation,
and total latency. A counter circuit is not a voice circuit benchmark.

The pilot target is 20–50 participants, three enrollment samples, ten genuine
attempts, and three impostor attempts per participant. This is an exploratory pilot,
not evidence for a low population false acceptance rate. Include replay and
real-time synthesis attacks before defining a release threshold.
